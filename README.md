# case式を用いた年齢層、性別ごとの入院件数と平均医療費の集計
このリポジトリは、case式を用いて年齢層、性別ごとの医療コストを集計する過程でcase式の条件分岐を修得することを目的としています。  

## 概要  
- 使用するDBMS:MySQL  
- 主な目的:case式の修得  
- 実行環境:DBeaver  

| ファイル名 | 説明 | 使用した主要な構文 |
| :-- | :-- | :-- |
| case1 | 年齢層及び性別ごとの医療コスト | case,round,join |

## 工夫した点  
- case式の中でtimestampdiffを用い年齢層を区分、case式に別名を付与し、医療コストの集計に活用しました。
